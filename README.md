# Navalha Mobile

App do Navalha para clientes e barbeiros: o cliente agenda e acompanha os horários, e o barbeiro vê o dia e bloqueia horários. Consome a [API do Navalha](https://github.com/lleonardooalves/navalha-api).

## Stack

React Native, Expo SDK 58, Expo Router e TypeScript.

## Rodando

```bash
npm install
npx expo start
```

## Scripts

| Comando                | O que faz                                      |
| ---------------------- | ---------------------------------------------- |
| `npm start`            | Sobe o Metro e mostra o QR code para o Expo Go |
| `npm run format`       | Formata o projeto com o Prettier               |
| `npm run format:check` | Confere a formatação (roda no CI)              |
